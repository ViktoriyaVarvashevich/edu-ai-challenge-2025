**Title**  
Logout Button Unresponsive in Safari

**Description**  
When attempting to log out of the application using the "Logout" button in the Safari browser, the button does not perform any action. This issue appears to be specific to Safari and prevents users from ending their sessions properly.

**Steps to Reproduce**  
1. Open the application in the Safari browser  
2. Log in with valid credentials  
3. Click the "Logout" button in the navigation menu  

**Expected vs Actual Behavior**  
*Expected:* The user should be logged out and redirected to the login or home page  
*Actual:* Clicking the "Logout" button does nothing; no response is observed  

**Environment (if known)**  
Browser: Safari (version not specified)

**Severity or Impact**  
High — Users on Safari cannot log out, which creates usability and security concerns
